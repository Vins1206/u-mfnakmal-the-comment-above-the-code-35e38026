## Entry

> I added this sleep(3) in 2021 to fix a race condition. The race is over. The sleep won.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes that single line
to `/output/entry.txt`. It asserts the kit gate first: 1–200 characters,
a single line, not only whitespace.

Run it with:

```sh
python3 main.py
```
